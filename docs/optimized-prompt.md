# 优化后的标准化 Prompt

你是一名资深前端工程师。请交付可独立安装、运行、构建和测试的 Vue 2.7 Options API + JavaScript + Less 项目，用于基金投资研究平台。

## 输入与优先级

1. 产品需求确定业务功能；截图确定视觉风格；设计系统确定组件令牌与状态。
2. 列表采用需求指定的全宽布局，不显示左侧菜单；详情采用设计图 2 的 220px 侧栏。
3. 品牌色使用截图与原始主色板中的 #D21F3E，在令牌定义文件统一覆盖文档中残留的蓝色品牌语义值；链接和图表仍采用独立蓝色令牌。
4. BFE 为内部库，若无包名、安装权限与 API 文档，提供明确标识的本地 bfe-\* 兼容层，不得声称使用了真实内部库。后续通过适配层替换。

## 页面及交互

- 顶部 46px 导航、红色品牌、白底内容卡片、浅灰页面背景、14px 中文正文、数字等宽呈现。桌面参考宽 1440px，移动端允许表格内部横向滚动。
- 列表：默认存续中；三种运行状态互斥，关键字模糊搜索；投资类型、基本信息、交易状态多选；已选标签双向联动；查询和条件变化重置页码；重置恢复初始值。
- 显示产品名称、代码、状态、经理、成立日期、月/半年/成立以来收益。产品名跳转 /fund/product/:code。正收益红、负收益绿、零为默认文字色，均保留两位小数。
- 批量选择以产品 ID 为准；翻页或过滤清空选择；全选支持半选。入池前校验非空和合法 ID，操作期间防重复。
- 导出全部指当前已提交筛选条件下的全部匹配产品；导出选中仅含选择项，未选择时禁用；模拟 2 秒后生成可下载 CSV。
- 详情按截图实现产品摘要、页签、产品收益折线、区间表、胜率柱图、持续性排名、盈利概率。所有记录来自异步服务。区间切换真实改变图表，关注可切换，分享复制地址。
- 其他无数据页签明确展示暂无数据，禁止虚构真实金融分析。

## API 与数据约定

将 API 和模拟数据独立于视图：getFilterOptions、getProductList、addToPool、exportProducts、getProductDetail。模拟 500ms 延迟，导出 2 秒。生成 50 条独立 ID 与产品代码的模拟产品，覆盖所有状态和正/负/零收益。筛选必须实际作用于结果；同维度多选 OR，基本信息跨条件 AND。返回 {total,list}，分页在过滤后执行。
使用请求序号避免快速筛选时旧结果覆盖新结果。所有异步操作处理 catch/finally、loading、空态和重试；提供可复现的模拟失败入口。

## 校验与可访问性

关键字最多 60 字符；分页只接收正整数页码和 10/20/50 条；非空产品 ID 校验。所有表单有标签、图标按钮有 aria-label、焦点可见、支持键盘，颜色配合符号及文字表达。
颜色原值仅可在令牌定义文件出现，组件全部使用 CSS 变量；样式隔离、BEM 组件命名、交互过渡 0.2s ease-in-out。不可用在线真实基金数据冒充模拟数据。

## 交付与验收

交付完整项目（含 FundProductList.vue 的 template/script/style lang=less scoped）、模拟服务、BFE 适配层、运行说明、优化说明、自动测试和视觉截图。
构建通过；测试 50 条完整性、组合过滤、分页不重复、ID 校验、错误恢复和收益格式。浏览器验证查询、多选标签移除、分页、入池、导出文件、空态、异常重试、详情路由、图表切换及 390px 响应式。记录实际结果与尚未实现范围。

# 优化思路

1. 明确冲突裁决：原 Prompt 与截图在侧栏、品牌色、列顺序、分页选中态上有差异。固定功能/视觉/令牌职责，减少生成结果漂移。
2. 从单文件提升为可运行交付：保留目标 Vue 文件，但将 API、数据、令牌和 BFE 兼容层拆分，方便接真实后端与内部组件。
3. 将“数据不写死”落实为视图无产品常量：模拟数据服务提供可重复的数据，所有视图通过 Promise 取得，不依赖静态 HTML。
4. 规定筛选逻辑、分页时机、导出范围与选择清理规则，避免只做视觉反馈而没有实际数据行为。
5. 增加异步竞态保护、失败注入、参数与 ID 验证，让验收覆盖异常路径。
6. 让图表与交互建立数据关联，并明确无数据页签边界，避免装饰性按钮和虚构分析。
7. 验收可复现：命令行测试 + 真浏览器交互 + 桌面和移动截图，共同验证逻辑与渲染。
