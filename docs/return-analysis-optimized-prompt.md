# 收益分析页：优化后的标准化 Prompt

## 角色与交付

你是一名资深前端工程师，使用 Vue 2.7 Options API、JavaScript、Less。主页面文件命名为 `ProductDetailReturn.vue`，按 template → script → style lang="less" scoped 组织，关键异步与校验代码写中文注释。交付完整可运行项目、模拟服务、测试及截图。

## 输入优先级与边界

- 业务交互以本 Prompt 为准；1440px 视觉基准参照设计图 2；颜色、排版、组件状态遵守给定 SKILL.md。
- 统一品牌红令牌；原设计文档中蓝色品牌映射与红色主色板冲突，红色用于导航/选中态，蓝色保留为链接、信息标签和数据序列色。颜色原值只在令牌定义文件中出现。
- 未提供内部 BFE 包时，明确使用可替换的本地 `bfe-*` 适配层，禁止声称已接入内部 BFE。覆盖 bfe-menu、bfe-tabs、bfe-tab-pane、bfe-tag、bfe-table、bfe-spin、bfe-message。
- 只实现收益分析内容；其他 7 个功能页签跳转对应路由并显示未接入数据说明。不能用仅改变选中颜色冒充路由跳转。

## 布局

顶部 46px 红色导航；左侧 220px 白色配置化菜单；主区浅灰背景、24px 边距、白色 4px 圆角区块。侧栏菜单数据驱动且可展开、收起和切换选中；基金产品默认选中。
面包屑：基金产品（可返回列表）/产品详情/存续期。头部显示接口返回的产品名称、代码、类型、风险、存续状态、经理、公司与成立/到期日期；无到期日显示“无固定到期日”。保留样图中的关注、分享交互。
一级 8 个页签：基本信息/收益分析/风险分析/基金经理/资产配置/债券分析/特色指标/相关公告；默认收益分析，选中红字及 2px 下划线。
二级周期置于收益内容顶部：近一周/近一月/近三月/近六月/近一年/成立以来，默认近一周。周期请求键必须为 week/month/quarter/halfYear/year/since。

## API、数据与加载规则

- `getProductBaseInfo(code)` 与 `getReturnAnalysis(code, 'week')` 初始化并行请求，各自 500ms 模拟延迟、独立 loading/error 与重试。
- 切换周期仅重新查询收益接口，不重复获取头部。快速切换周期或产品时，以请求序号拒绝旧响应，旧请求的 finally 也不能提前关闭新请求 loading。
- 产品数据统一来自模拟服务；视图不包含产品记录、收益常量和排名记录。每个周期返回不同数值、曲线与分析数据，曲线末值必须与当前周期收益表一致。
- 本页继续保留产品收益曲线、胜率、持续性与盈利概率分析，图表和表格全部消费同次接口响应，不保留上一周期的旧图。
- 无数据返回 rows:[]；异常拒绝 Promise。提供折叠的模拟演示入口，可复现空数据、收益异常和头部异常，正常重试可恢复。

## 收益表契约与冲突裁决

原文同时要求单周期汇总行，以及同周期内覆盖正负零与四档排名，单行无法同时满足。因此每周期固定返回 4 条模拟指标：区间主收益率、最佳滚动收益、最差滚动收益、现金比较收益。它们只是本地演示指标；不声称为真实金融指标计算。
每行字段：metric、myProduct（number|null）、median（number|null）、quartile（优秀/良好/一般/不佳）、peerRank（正整数名次/正整数总数）。
五列：收益指标/本产品/同类中位数/四分位排名/同类排名。不分页；行高 52px，padding 9px 16px，浅灰表头和水平分割线。

- 收益正数红色并带+，负数绿色，零默认文字色，均 2 位小数；空值/非有效数显示 --；微小负数舍入为 0 时不得显示 -0.00%。
- 排名标签：优秀 success、良好 info、一般 neutral、不佳 danger。每周期覆盖四种枚举，正负零及 null 均可验证。
- “排名靠前”明确定义为名次/总数 ≤25%，仅这些排名使用品牌色强调；校验 1≤ 名次 ≤ 总数、分母大于 0。

## 路由与可访问性

保留 `/fund/product/:code` 入口，并支持 `/fund/product/:code/return` 以及 base-info/risk/manager/allocation/bonds/indicators/announcements 子路由。Hash 路由支持静态托管及刷新；切换产品重置周期、关注和旧提示。
基金代码必须 6 位数字且存在于产品集，周期必须来自枚举，接口 rows 结构、收益数值、排名与枚举都要校验。
页签使用 tablist/tab/tabpanel、aria-selected 与有效关联 ID；方向键/Home/End 移动焦点、Enter/Space 激活；按钮和表单支持键盘、焦点清晰。移动端隐藏侧栏、分析区变单列、表格仅在内部横向滚动，不撑宽页面。

# 优化思路

1. **消除数据要求矛盾**：明确单周期使用 4 条模拟指标，覆盖原需求要求的全部标签和值类型，而不是隐式忽略任一要求。
2. **周期切换变为真实异步行为**：原版仅从已加载数据中切换曲线；新版每次调用收益接口，头部不重复请求，表格和图表共用本次响应。
3. **隔离异步状态**：分别管理头部/收益 loading、错误及请求序号；一方失败不会掩盖另一方内容。
4. **明确数据口径**：前 25%作为排名强调阈值，null 不等同 0，统一百分比格式，舍入后的负零也正确处理；到期日缺失有明确文案。
5. **明确可运行条件**：外置 API 和 BFE 适配层，同时保留指定 Vue 单文件，方便后续替换真实接口及组件库。
6. **完善路由和键盘行为**：一级页签拥有可刷新 URL，二级页签支持键盘；侧栏选中与展开按配置处理。
7. **建立视觉与逻辑双重验收**：自动断言覆盖数据和错误路径，截图复核发现并修复插槽样式作用域导致的按钮对齐问题。
