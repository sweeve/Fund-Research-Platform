## 新增验证范围
1. 六个周期分别请求且返回不同汇总数据；近一年绝对值大于近一周；曲线末值与当前收益指标一致。
2. 每周期表格包含正数、负数、零、空值及四档排名标签，前25%排名品牌色强调。
3. 缺失数值显示--，有效零显示0.00%，负零舍入正常。
4. 基金代码格式、产品存在性、周期枚举、收益结构、数值与同类排名分子分母校验。
5. 周期切换时收益表loading、头部保持可见；快速切换后的最终内容匹配最后选中周期。
6. 空数据、收益接口异常、头部接口异常均可复现，头部与收益互不遮挡并分别重试恢复。
7. 一级页签URL跳转、路由刷新、回到收益分析、面包屑返回产品列表。
8. 页签方向键与Enter操作、关注切换、侧栏选中。
9. 390px无页面级横向溢出，表格可在内部滚动；浏览器未捕获pageerror。
