## 1. 核心优先级

生成任何 UI 元素时，颜色选择遵循以下优先级：

1. **语义颜色（第 4 节）** → 如 `color-brand`、`color-danger-text`
2. **中性颜色（第 3 节）** → 如 `color-text-1`、`color-fill-2`
3. **数据色板（第 2 节）** → 如 `color-data-1`、`color-data-20`
4. **原始调色盘（第 1 节）** → 如 `color-primary-6`（仅在语义未覆盖时使用）

---

## 2. 颜色梯度语义（适用于所有色相）

调色盘中每个色相的梯度（-1 到 -10）对应以下使用场景：

| 梯度 | 语义 |
|------|------|
| `-1` | 浅色背景、表头、悬浮背景 |
| `-2` | 特殊场景、浅边框、悬停背景加深 |
| `-3` | 禁用背景、浅色边框 |
| `-4` | 常规边框、次级填充 |
| `-5` | 悬浮状态（按钮、链接） |
| `-6` | 常规/主要颜色（主按钮、主要文字） |
| `-7` | 点击/激活状态 |
| `-8`、`-9`、`-10` | 加深扩展，用于强调、渐变或特殊需求 |

> 例如：`color-primary-3` 适用于禁用状态，`color-primary-6` 是品牌主色。

## 3. 字体选择规则

### 语言判断规则
- **文本内容为中文** → 使用 `*/CN-*` 令牌（PingFang SC）
- **文本内容为英文/数字/混排** → 优先使用 `*/EN-*` 令牌（Nunito Sans）

### 中文字体（PingFang SC）
- **多行段落正文** → 优先使用 `14/CN-段落-Regular`（行高 21px，更紧凑）
- **单行正文/按钮/导航** → 使用 `14/CN-Regular` 或 `14/CN-Medium`
- **标题层级**：
  - H1 → `48/CN-Medium`
  - H2 → `36/CN-Medium`
  - H3 → `24/CN-Medium`
  - H4 → `20/CN-Medium`
- **辅助/小字** → `12/CN-Regular` 或 `12/CN-Medium`

### 英文字体（Nunito Sans）
- 与中文保持相同字号，但使用 `*/EN-*` 令牌
- **强调英文/数字** → 可使用 `14/EN-Bold`

## 5. 通用规则

本章节定义的规则适用于所有组件，是组件规范的基础。

### 5.1 CSS 变量与样式隔离
- **强制使用令牌**：所有样式代码（CSS/Less/Sass）中**禁止硬编码**色值（如 `#165dff`），必须使用 `var(--color-primary-6)` 等设计令牌。
- **样式隔离**：组件样式应通过 CSS Modules、Shadow DOM 或 Scoped CSS 进行隔离，避免全局样式污染。

### 5.2 类名命名规范（BEM）
所有组件类名遵循 BEM（Block Element Modifier）命名规范：
- **Block**：组件最外层容器，如 `.a-button`
- **Element**：组件内部子元素，如 `.a-button__icon`
- **Modifier**：组件状态或变体，如 `.a-button--primary`、`.a-button--disabled`

### 5.3 动效与过渡规范
- **过渡属性**：所有交互反馈（悬停、激活、展开/收起）必须使用 `transition`，禁止瞬间变化。
- **时长与曲线**：统一使用 `0.2s ease-in-out`。
- **例外**：禁用状态切换（如 disabled）无需过渡动画。

### 5.4 响应式断点规范
所有响应式组件（如栅格、日历、表格）必须遵循以下断点：

| 断点名称 | 最小宽度 | 适用设备 |
|----------|----------|----------|
| `xs` | — | 手机（< 576px） |
| `sm` | 576px | 大屏手机/小平板 |
| `md` | 768px | 平板 |
| `lg` | 992px | 桌面 |
| `xl` | 1200px | 大桌面 |

### 5.5 无障碍基础要求
- 所有交互元素（按钮、链接、输入框等）必须支持键盘操作（`Tab` 键导航、`Enter`/`Space` 键激活）。
- 所有图标按钮必须添加 `aria-label` 属性。
- 颜色不得作为传递信息的唯一手段（需配合文字或图标）。
- 聚焦指示器必须清晰可见，禁止移除 `outline` 而不提供替代样式。

## 6. 组件规范

### 6.1 <a-button> 按钮

#### 输入要求
Figma 按钮节点应包含以下属性（或从图层名解析）：
- `类型`：主要 / 次要 / 虚线 / 线框 / 文本
- `种类`：标准 / 危险 / 警告 / 成功
- `形状`：长方形 / 全圆角 / 方形 / 圆形
- `尺寸`：迷你 / 小 / 中 / 大
- `状态`：默认 / 悬停 / 聚焦 / 激活 / 禁用

#### 映射规则

##### 1. 属性映射

| Figma 属性 | 值 | 样式规则 |
|-----------|-----|----------|
| **类型** | 主要 | 背景 `primary-*`，文字白色 |
| | 次要 | 背景 `fill-*`，文字 `text-*` |
| | 虚线 | 背景 `fill-*`，文字 `text-*`，边框 `1px dashed`，**边框颜色见下方状态表** |
| | 线框 | 无背景，边框+文字梯度同主要按钮背景；边框宽 `1px`、样式 `solid` |
| | 文本 | 无边框，文字梯度同线框 |
| **种类** | 标准 | 令牌前缀 `primary-*` |
| | 危险 | 令牌前缀 `red-*` |
| | 警告 | 令牌前缀 `orange-*` |
| | 成功 | 令牌前缀 `green-*` |
| **形状** | 长方形 | 圆角 `2px`，左右内边距 `16px` |
| | 全圆角 | 圆角 = 高度 / 2（例如中尺寸 32px → `16px`） |
| | 方形 | 宽高 = 当前尺寸高度（迷你24px，小28px，中32px，大36px），圆角 `2px`，仅图标，无文字 |
| | 圆形 | 宽高 = 当前尺寸高度，圆角 `50%`，仅图标，无文字 |
| **尺寸** | 迷你 | 高度 `24px`，字号 `12px`，图标尺寸 `12px` |
| | 小 | 高度 `28px`，字号 `14px`，图标尺寸 `14px` |
| | 中 | 高度 `32px`，字号 `14px`，图标尺寸 `14px` |
| | 大 | 高度 `36px`，字号 `14px`，图标尺寸 `14px` |

> **图标按钮补充**：
> - 带文字的图标按钮：图标与文字间距 `gap: 4px`，图标尺寸同字号。
> - 仅图标按钮（方形/圆形）必须设置 `aria-label` 描述操作。

##### 2. 状态样式

**主要按钮**（背景填充，文字白色）

**次要按钮（危险/警告/成功种类）**

**虚线按钮**
虚线按钮的背景和文字规则**完全同次要按钮**。
边框规则：

**标准种类虚线按钮**：

### 6.9 <Form> 表单

#### 概述
用于数据采集、校验和提交的容器组件，由数据录入类组件与标签（label）说明构成，支持多种布局方式和尺寸。

#### 属性

| 属性 | 可选值 | 说明 |
|------|--------|------|
| 组件类型 | `input` / `select` / `textarea` / `datepicker` / `radio` / `checkbox` / `switch` / `slider` / `rate` / `upload` | Form表单控件类型，决定渲染的数据录入组件 |
| 布局 | 水平 / 垂直 | label 与表单控件的排列方向，默认水平 |
| 尺寸 | 迷你 / 小 / 中 / 大 | 仅对 input / select / textarea / datepicker 生效，高度对应 24px / 28px / 32px / 36px，组件文字 14/Regular；`label` 文字 14/Regular，`text-2` |

#### label 与组件布局规则

| 布局模式 | label对齐 | label 与控件间距 | 排列方向 |
|------|--------|------|------|
| 水平 | 右对齐 | 16px | 左右排列 |
| 垂直 | 左对齐 | 16px | 上下排列 |

#### 表单页面布局与间距规则
表单页面采用 Flexbox 布局与栅格系统，默认为三列布局，各表单控件宽度自适应。

| 间距类型 | 值 | 说明 |
|------|--------|------|
| 表单元素垂直间距 | 20px | 各组 label + 控件 之间的纵向间距 |
| 表单元素水平间距 | 24px | 栅格列与列之间的横向间距 |

#### 通用规则
- **必填标识**：必填项 label 前显示红色星号，表单提交时校验，若为空则阻断提交并提示
- **冒号**：label 文字与控件之间显示冒号（:），默认不显示
- **提示文字**：label 右侧显示问号图标（`fill-4`），悬浮时弹出文字提示，用于辅助说明
- **辅助文字**：控件下方显示辅助文字，用于说明填写规则或格式要求，常规提示使用 `fill-4`，错误提示使用 `danger-6`
- **按钮原则**：按钮展示在表单底部，与最后一个表单项保持固定间距；默认与组件左对齐；从左至右依次展示主要按钮（提交按钮）、次要按钮（返回按钮），按钮间距 16px

### 6.10 <Charts> 图表

#### 属性

| 属性 | 可选值 | 说明 |
|------|--------|------|
| 图表类型 | 折线图 `Area Chart` / 柱状图-垂直 `Bar Chart (Vertical)` / 柱状图-水平 `Bar Chart (Horizontal)` / 饼图 `Pie Chart` / 南丁格尔玫瑰图 `Rose Chart` / 仪表盘图 `Gauge Chart` | 常用 VChart 图表类型 |
| 图表色板 | N≤10 / 10≤N≤20 | 数据组不超过10个时，采用奇数编号的数据色板，依次使用 `color-data-1`、`color-data-3`、`color-data-5` 等，以此类推；数据组超过10个时，依次使用 `color-data-1` 至 `color-data-20` |

#### 颜色覆盖规则（数据色板 vs 语义色板）
1. **数据序列色板**：数据组不超过 10 个时，采用奇数编号的数据色板（`color-data-1`、`-3`...）；超过 10 个时，依次使用 `color-data-1` 至 `color-data-20`。
2. **语义标注覆盖**：图表中的警戒线、异常值标注、趋势描述文本等非数据序列元素，**必须优先使用语义颜色**（如异常值用 `color-danger-text`，达标线用 `color-success-text`）。
3. **冲突解决**：当数据色板与语义颜色视觉上可能混淆时，优先保留语义颜色的辨识度（如通过形状、图例或文字标注辅助区分）。

### 6.11 <Calendar> 日历

#### 输入要求
Figma 日历节点应包含以下属性（或从图层名解析）：
- `视图`：`月` / `年`
- `下拉选择`：`true` / `false`

#### 属性与变体

| 属性 | 可选值 | 说明 |
|------|--------|------|
| `视图` | `月` / `年` | 日历显示模式 |
| `下拉选择` | `true` / `false` | 是否启用下拉选择器 |

共有 4 个有效变体（全组合）：

| 变体编号 | 视图 | 下拉选择 |
|----------|------|----------|
| 1 | `月` | `false` |
| 2 | `月` | `true` |
| 3 | `年` | `true` |
| 4 | `年` | `false` |

#### 布局与基础样式

| 属性 | 值 |
|------|----|
| 尺寸 | 宽度 980px × 高度 758px（自适应） |
| 内边距 | 20px 24px 24px |
| 圆角 | 2px |
| 背景 | `color-bg-card` |
| 容器层级 | 投影使用 `shadow-drop-1` |
| 边框 | `color-border-2` 实线 1px |
| 主字体（标题） | Nunito Sans，20px，SemiBold |
| 日期字体 | PingFang SC，14px，Regular/Medium |
| 行/列间距 | 4px |

#### 交互行为与功能要求

**通用交互（适用于所有变体）**：
1. **视图切换**：右上角提供“月”和“年”按钮，点击后切换视图模式，保持当前年月不变。
2. **月份导航（月视图）**：左右箭头点击后，当前月份 ±1，年随月份跨年自动调整。
3. **年份导航（年视图）**：左右箭头点击后，当前年份 ±1，月份保持不变（年视图下显示该年全部12个月）。
4. **纯净视图约束**：日历容器内禁止添加任何非日期核心内容的装饰性模块（如统计图表、任务看板、侧边说明等），除非用户明确要求。

**无下拉选择（`下拉选择=false`）**：
- **左上角标题**：显示 `YYYY年 M月` 格式（如 `2026年 6月`），文本不可编辑。
- **左右箭头**：位于标题两侧，点击触发月份/年份切换。
- **视图切换**：右上角月/年按钮切换视图。

**有下拉选择（`下拉选择=true`）**：
- **左上角标题**：分别显示“年”和“月”为独立可点击区域，点击后弹出下拉列表。
  - 年下拉：列出可选年份（如 2020 ~ 2049），当前年份高亮。
  - 月下拉：列出 1~12 月，当前月份高亮。
- **选择后**：日历立即更新至所选年月，下拉面板自动关闭。
- **左右箭头**：仍保留，点击后切换年月，标题同步更新。

**年视图特有要求**：
- **展示方式**：将所有 12 个月份均匀排列在一个整体卡片内，每行 3 个月份。
- **网格比例**：在桌面端（1200px+）下，建议通过 `max-width` 限制组件宽度或增加外边距，确保 12 个月份块保持紧凑的网格比例。
- **月份块**：每个月份块包含月份名称（中文）以及该月的完整日期网格（从 1 日到月底），日期数字使用小号字体（10px）展示。
- **当前月高亮**：与系统当前月份匹配的月份块，其月份名称使用品牌色并加粗，同时日期数字颜色加深。
- **今天标记**：在年视图中，若某天是“今天”，该日期数字使用品牌色边框（1px）高亮。

#### 响应式适配策略

| 断点 | 月视图行为 | 年视图行为 |
|------|------------|------------|
| **≥ 1200px (xl)** | 标准 7 列布局，日期字号 14px | 每行 3 个月份块，日期字号 10px |
| **≥ 768px (md)** | 标准 7 列布局，日期字号 14px | 每行 3 个月份块，日期字号 10px |
| **≥ 576px (sm)** | 标准 7 列布局，日期字号 12px | 每行 2 个月份块，日期字号 9px |
| **< 576px (xs)** | 标准 7 列布局，日期字号 10px，左右内边距缩减 | 每行 2 个月份块，日期字号 8px |

> **通用原则**：日期单元格的最小触控区域（在移动端）应不低于 28px × 28px。

**月视图样式**：

| 元素 | 样式 |

| 标题（年份/月份） | 品牌色 `color-brand`，20px，加粗 |
| 下拉触发器（有下拉时） | 悬停背景 `fill-2`，下拉箭头使用 `text-4` |

### 6.12 <Card> 卡片

#### 输入要求
- `简洁`：`true` / `false`
- `边框`：`true` / `false`

#### 变体属性与组合

卡片组件具有 **“简洁 (Concise)”** 和 **“边框 (Border)”** 两个核心属性，共 4 种组合变体：

| 变体名称 | 简洁 (Concise) | 边框 (Border) | 视觉特征 |
|----------|----------------|---------------|----------|
| **标准带框卡片** | `false` | `true` | 包含标题区（带下划线）和主体区，外围有 1px 边框 |
| **标准无框卡片** | `false` | `false` | 包含标题区（带下划线）和主体区，仅依靠阴影区分层级 |
| **简洁带框卡片** | `true` | `true` | **仅保留标题区**，高度固定 60px，外围有 1px 边框 |
| **简洁无框卡片** | `true` | `false` | **仅保留标题区**，高度固定 60px，无外边框 |

#### 基础样式

| 属性 | 令牌 (Token) / 值 | 说明 |
|------|-------------------|------|
| 背景色 | `color-bg-card` | 默认白色容器背景 |
| 边框 | `color-border-2` | 1px 实线，轻量级分割 |
| 圆角 | 4px | 符合 Precision Enterprise 规范 |
| 投影 | `shadow-drop-1` | `0 4px 10px rgba(0,0,0,0.1)`，增强层级感 |
| 默认内边距 | 20px (Top/Right/Bottom/Left) | 确保内容呼吸感 |

#### 结构组件

1. **Header (头部)**：
   - 标题居左，操作项（固定为“More”链接或按钮）居右。
   - **所有变体通配**：标题区右侧统一展示“More”链接（或带箭头的 More 字样）。
   - **简洁=false**：底部通过 `color-border-2` 进行 1px 分割线。
   - **简洁=true**：**移除标题底部分割线**。容器高度固定为 **60px**，内部标题与操作项必须 **垂直居中对齐**，且确保内容单行显示，**严禁出现换行**。

2. **Body (主体)**：
   - 卡片核心内容区，自适应高度。
   - **简洁=false**：仅包含描述文本，**严禁包含图片、插画、页脚或装饰性模块**。
   - **简洁=true**：**彻底移除 Body 部分**。

3. **Footer (页脚)**：
   - **所有变体通配**：**彻底移除 Footer 部分**，除非用户明确要求。

#### 交互行为与设计约束

1. **极致纯净化**：标准卡片主体仅保留文字内容；简洁卡片表现为横条式列表项，严禁在标题或操作项处产生任何垂直堆叠或换行。
2. **纯净视图约束**：在展示或生成卡片组件页面时，**默认情况下禁止**添加任何非核心内容的装饰性模块（如视觉结构说明、网格对齐示例等）。**若用户明确要求**添加说明性占位或示例数据，可酌情展示，但需确保不影响核心组件本身的样式表现。
3. **响应式**：在栅格系统中，卡片应根据容器宽度自适应，内部内容需处理好长文本溢出（省略号）。
4. **一致性**：同一页面内的多个卡片应保持相同的圆角、内边距和标题层级。

# 6.27 <Breadcrumb> 面包屑

## 1. 核心优先级

生成 Breadcrumb 元素时，颜色选择遵循以下优先级：
1. **语义颜色** → 如 `color-text-2`（默认文本）、`color-text-1`（悬停文本）
2. **中性颜色** → 如 `color-bg-hover`（悬停背景）
3. **令牌系统** → 严格遵循 `DESIGN.md` 定义的文字与背景令牌

## 2. 交互状态语义

| 状态 | 文本颜色 | 背景颜色 | 交互表现 |
|------|---------|---------|---------|
| **默认 (Default)** | `color-text-2` | 透明 | 鼠标手势 `pointer`，带下划线或链接感 |
| **悬停 (Hover)** | `color-text-1` | `color-bg-hover` | 矩形微量背景填充，圆角 2px |
| **当前页 (Current)** | `color-text-3` | 透明 | 鼠标手势 `default`，无链接，不可点击 |
| **禁用 (Disabled)** | `color-text-4` | 透明 | 鼠标手势 `not-allowed` |

## 3. 字体与排版规则

### 基础样式
- **对齐**：左对齐，垂直居中

### 分隔符样式
- **默认符号**：`/`
- **颜色**：`color-text-4`
- **间距**：分隔符左右间距各 4px

## 4. 组件构成与属性

### Breadcrumb.Item (子项)
- **内容类型**：纯文本 / 图标+文本 / 纯图标
- **图标间距**：图标与文字间距 4px，图标尺寸 14px
- **最大宽度**：支持过长文本省略（Text Overflow: Ellipsis）

### 省略号变体 (Ellipsis)
- **触发条件**：层级超过 `maxCount` 时
- **表现形式**：中间层级折叠为 `...`
- **交互**：悬停在 `...` 上时通常触发 Dropdown 或 Tooltip 显示完整路径

## 5. 布局与间距

- **容器高度**：自适应或固定 32px（中尺寸）
- **内边距**：子项水平内边距 4px（悬停背景范围）
- **整体位置**：通常位于页面标题下方或内容区域最顶部，下方间距 16px-24px

| **进行中 (Process)** | 背景 `color-brand`，文字 `white` | `color-text-1` | `color-text-2` | `color-fill-3` |
| **完成 (Finish)** | 边框 `color-brand`，图标 `color-brand` | `color-text-1` | `color-text-2` | `color-brand` |

- **特点**：图标替换为 8px 无边框正圆点，风格极简。

### C. 导航型步骤条 (Navigation)
- **特点**：带背景填充的条状导航，常用于页签切换风格的流程。
- **样式**：
  - 进行中：底部 2px `color-brand` 实线，文字 `color-brand`。
  - 完成：文字 `color-text-1`。

### D. 箭头型步骤条 (Arrow)
- **特点**：各项之间以箭头形状衔接，视觉指向性强。
- **样式**：常用于全宽度的流程引导，背景颜色区分状态。

## 4. 组件构成与属性
- **内容**：步骤序号/图标 + 标题 + 描述文字（可选）
- **图标尺寸**：标准 32px / 小型 24px
- **连接线**：高度 1px，间距图标左右各 12px

## 5. 布局与间距
- **间距**：步骤项之间水平等分或固定间距
- **横向布局**：标题与描述在图标下方（居中）或右侧（左对齐）
- **垂直布局**：用于侧边栏或长表单流程，描述文字位于标题下方，间距 4px，连接线垂直位于图标中心下方。
- **容器内边距**：通常水平 `px-md`
- **步骤项最小宽度**：120px（横向且标题在下方时）

- **图标间距**：图标与文字间距 `8px`

## 5. 布局与间距
- **最大宽度**：`520px`
- **层级 (Z-index)**：`1010`

# 6.33 <Modal> 对话框

## 1. 核心优先级

生成 Modal 元素时，颜色选择遵循以下优先级：
1. **语义颜色** → 如 `color-brand`（主要操作）、`color-danger-text`（危险确认）、`color-info-text`（提示图标）
2. **中性颜色** → 如 `color-bg-card`（容器背景）、`color-text-1`（标题）、`color-text-2`（正文）
3. **令牌系统** → 严格遵循 `DESIGN.md` 定义的投影、圆角与遮罩令牌

## 2. 布局模态分类 (Layout Modalities)

根据业务场景，Modal 分为 **标准型 (Standard)** 与 **消息提示型 (Notification)** 两种模态。

| 属性 | 标准型 (Standard) | 消息提示型 (Notificatione) |
|------|-----------------|---------------------|
| **适用场景** | 复杂信息展示、表单录入、数据确认 | 简短状态告知、操作反馈、二次确认 |
| **标题栏布局** | 标题居中，带右侧关闭图标 (Close Icon) | 图标与标题水平居中同行，不设关闭图标 |
| **内容对齐** | 文本/表单左对齐 | 文本/表单左对齐 |
| **页脚布局** | 按钮右对齐 (justify-end) | 按钮居中对齐 (justify-center) |
| **宽度规格** | 标准 520px | 紧凑型 400px |

## 3. 交互状态语义映射

| 类型 | 图标颜色 | 确认按钮样式 | 取消按钮样式 | 布局模态 |
|------|---------|---------|---------|---------|
| **通用 (Standard)** | 无 | 主要按钮 (`color-brand`) | 次要按钮 (`color-fill-2`) | 标准型 |
| **信息 (Info)** | `color-info-text` | 主要按钮 (`color-brand`) | 无 | 消息提示型 |
| **成功 (Success)** | `color-success-text` | 主要按钮 (`color-brand`) | 无 | 消息提示型 |
| **警告 (Warning)** | `color-warning-text` | 主要按钮 (`color-brand`) | 无 | 消息提示型 |
| **错误/确认 (Danger)** | `color-danger-text` | 危险按钮 (`color-red-6`) | 次要按钮 (`color-fill-2`) | 消息提示型 |

## 4. 间距与尺寸规格 (规格参数)

### 消息提示型特定参数 (Message Specifics)
- **图标尺寸**：20px 核心图形
- **行内间距**：图标与标题文字间距 **8px**
- **内容区 (Content)**：与页面页尾间距 **24px**
- **垂直对齐**：图标与标题文字基线居中对齐
- **内边距**：容器 p-8 (32px)，确保呼吸感

### 通用令牌
- **圆角**：`ROUND_FOUR` (4px)
- **投影**：`shadow-drop-2`
- **遮罩**：`color-bg-modal-mask`


## 5. 组件构成与细节

### Modal.Header
- **通用 (Standard)** ：下边框 `1px solid color-border-1`

### Modal.Footer
- **布局**：Flex 布局，`justify-content: flex-end`
- **按钮顺序**：[取消] [确定]
- **通用 (Standard)** ：上边框 `1px solid color-border-1`

### 异常处理
- **内容过长**：内容区最大高度建议为视口高度的 70%，超过则开启内部滚动。
- **确认删除场景**：标题突出显示“确认删除”，内容区需明确指出被删除的对象。

## 5. 字体与排版

- **标题 (Title)**：`16/CN-Medium`，颜色 `color-text-1`
- **正文 (Content)**：`14/CN-Regular`，颜色 `color-text-2`
- **按钮文字**：`14/CN-Regular`

## 7. 无障碍设计规范 (Accessibility)

### 7.1 颜色对比度标准 (WCAG 2.1)

- **AA 级标准**：
  - 普通文本（小于 18pt）与背景对比度 ≥ 4.5:1。
  - 大号文本（大于 18pt）与背景对比度 ≥ 3:1。
- **AAA 级标准（推荐）**：
  - 普通文本与背景对比度 ≥ 7:1。
- **验证方法**：使用 Chrome DevTools 的 Lighthouse 或 Contrast Checker 插件进行验证。

### 7.2 键盘导航 (Keyboard Navigation)

- **Tab 键顺序**：所有可交互元素（按钮、链接、输入框、下拉菜单）必须按逻辑顺序可聚焦。
- **焦点指示器**：聚焦状态必须清晰可见（如 `outline: 2px solid color-brand`），禁止移除 `outline` 而不提供替代样式。
- **Enter / Space 键**：按钮、链接、开关、菜单项必须支持 `Enter` 或 `Space` 键触发。
- **方向键**：下拉选择、选项卡列表、单选组应支持 `上下左右` 方向键切换选项。

### 7.3 屏幕阅读器支持 (ARIA)

- **角色声明**：复杂组件（如对话框、菜单、进度条）必须使用 `role` 属性声明其语义。
- **状态与属性**：必须使用 `aria-expanded`、`aria-selected`、`aria-disabled`、`aria-checked` 等属性动态反映组件状态。
- **标签与描述**：
  - 所有表单控件必须有对应的 `<label>` 标签，或使用 `aria-label` / `aria-labelledby`。
  - 图标按钮必须使用 `aria-label` 描述其操作含义（如 `aria-label="关闭"`）。
- **焦点管理**：在模态框或抽屉打开时，焦点应自动移入容器内，并在关闭时回到触发元素。

### 7.4 语义化 HTML

- 优先使用原生 HTML 元素（`<button>`、`<input>`、`<a>`），仅在原生无法满足需求时使用 `div` + ARIA 模拟。
- 列表结构使用 `<ul>` / `<ol>` / `<li>`。
- 表格结构使用 `<table>` / `<thead>` / `<tbody>` / `<th>` / `<td>`。
